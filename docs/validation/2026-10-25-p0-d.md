## 4. Decisions

Each decision below is a **controller recommendation, owner unavailable**.

- **The 0.5 % Z0/εeff limit** against the Windows reference (OI-8, PF-71). It is one model at one stop level, which r7 expects to agree within 0.1 %.
- **`p0d.PIN` holds mesh.reach_h at 3.0**, the P0 runs' reach. P0-B's raise of the product default to 6 (D-37) therefore does not move the models CI builds. The pre-check found all nine spec_hash values equal before the references were written, and the test confirms them after.
- **PF-69 did not fire.** OI-6 was not applied, so lpf915 gets no per-model t_max_s pin.
- **Trace cap.** `p0.TRACE_BYTES` was raised from 50 000 to 100 000 bytes (`356392d`). The probe samples are never thinned (PF-15), because thinning them would break D-48's exact replay and the 1e-12 check. See section 5.
- **fedora:44 is pinned** (D-47); upstream's CI follows fedora:latest.
