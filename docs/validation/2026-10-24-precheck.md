## Appendix: procedure as Task 16 ran it

Placeholders: `<repo>` is the work tree, `<venv>` the dev venv, `<P0>` the P0 folder, and `<KiCad bin>` KiCad 9.0's `bin` folder.

**A.1 Steps.** The script `<P0>/precheck/precheck.py` was written from Task 16's brief and never committed. It ran once from `<repo>`: `<venv>\Scripts\python.exe <P0>\precheck\precheck.py <P0>`.

1. The script creates `config`, `cache`, `temp`, `appdata`, `localappdata` and the plugin folder `documents/KiCad/9.0/plugins/krs precheck` under `<P0>/precheck`.
2. It builds the child environment from the current one. It drops every KICAD* variable, TMPDIR and KRS_PRIVATE_LIST, then sets the A-3 variables (section 2). Before each KiCad child it asserts that KICAD_CONFIG_HOME is inside `<P0>/precheck` and TMPDIR is absent. Each child is waited for, with a 300 s timeout.
3. It runs `<KiCad bin>\kicad-cli.exe version`, which also creates `config/9.0/kicad_common.json`. It then sets `api.enable_server = true` and `system.language = "English"` in that file.
4. It writes `plugin.json` (A.2), two blank PNG icons (24 and 48 px, drawn with matplotlib) and `launch.cmd` (A.3) into the plugin folder.
5. Loader: it runs `kicad-cli.exe version` again with `KICAD_ENABLE_WXTRACE=1` and `WXTRACE=KICAD_API`, and saves stderr as `<P0>/precheck/loader.log`.
6. Launch replay: it writes `<P0>/precheck/wx_launch.py` and runs it with `<KiCad bin>\pythonw.exe -I -B wx_launch.py "<plugin folder>" <uuid4 token>`, which uses KiCad's own wx, console-less. The replay does five things:
   - It quotes each argument that contains a space or tab, or is empty, as wxExecuteImpl does.
   - It sets `KICAD_API_SOCKET=ipc://%TMP%\kicad\api.sock` and `KICAD_API_TOKEN=<token>`.
   - It changes into the plugin folder.
   - It calls `wx.Execute(cmd, wx.EXEC_ASYNC | wx.EXEC_HIDE_CONSOLE)`.
   - It waits up to 10 s for `marker.txt`, then writes `replay.json` (pid, marker found).
7. Checks: the script computes the ten checks of section 3 from the version string, `loader.log`, `replay.json` and `marker.txt`. It adds `commit` (`git rev-parse --short HEAD`) and writes `<P0>/precheck/precheck.json`. It exits 0 only if every check except `commit` is true.

**A.3 `launch.cmd`**, as written (CRLF line ends):

```bat
@echo off
setlocal EnableDelayedExpansion
>>"%~dp0marker.txt" (
  echo marker=ok
  echo cwd=!CD!
  echo arg1=%~1
  echo arg2=%~2
  echo socket=!KICAD_API_SOCKET!
  echo token=!KICAD_API_TOKEN!
)
exit /b 0
```
