## 5. Stated limits and deviations

- **A-1 (spec §9.2 L546).** The triplet with MSLPort's equations replaces MSLPort. On the repo's one-cell solid strips, MSLPort's current probe reads 66–113 Ω. CPWPort agrees with the triplet to 0.09 % (r7 §2.2).
- **A-2 (spec §9.2 L547).** Masked absolute Z0 is checked against KiCad × the 2D mask factor, because KiCad has no mask. The mask shift is compared with fit2d's on-mesh shift, not the exact 2D shift.
- **Mask-shift resolution.** At n = 2 the mesh resolves about 80 % of the GCPW mask shift. In Z0 the FDTD reads −4.583 % against the 2D −5.755 %. In εeff it reads 9.979 % against 12.59 %. At n = 3 the Z0 shift is −4.96 %. fit2d's absolute gate bounds this gap (D-26).
- **KiCad's CPWG bias.** KiCad reads CPWG about +3.1 % above the 2D solver in Z0 (the research figure, r7). In this run coupon_gcpw's KiCad reference is 51.79 Ω and the 2D value is 50.2 Ω, which is +3.2 %.
- **2D reference box.** The 45 h box runs the dielectric past the coupons' board edge, while the FDTD substrate stops at the outline.
- **R-P2-20 (fit2d on GCPW at n = 2).** coupon_gcpw_masked at n = 2 has e_fit 3.781 %, so E_FIT2D stops it. FDTD tracks fit2d on that row at delta −0.1441 pp, so the block is real. On every axis-aligned GCPW row, delta lies between −0.2384 and +0.09404 pp.
- **R-P2-21 (lpf915 at n = 3).** No board fixture ran in P0-A. On the unmasked GCPW coupons, e_fit falls from about 2.5 % at n = 2 to about 1.9 % at n = 3 (masked GCPW: 3.781 % to 2.79 %), and on every GCPW row delta stays within 0.24 pp.
- **R-P2-27 (open rows E_FIT2D stops).** These stay stated limits. The FDTD evidence is the same delta_pp: at most 0.5293 pp on every row.
- **R-P2-23's price** (r3 A-3). On coupon_ms at n = 2, the rule uses 92/55 x/y lines at d = h/n, against 58/37 at d = w/n. The microstrip rows confirm it in FDTD: |dz0| is at most 0.8373 % and |deeff| at most 1.611 %.
- **Oblique εeff.** On the 45° mid-point planes, εeff reads 8.161–15.49 % above coupon_gcpw (A3). D-27 decides on Z0 only, so this is reported, not decided.
- **The refusal rests on one row.** It comes from coupon_gcpw_45 at n = 2 (−6.976 %). The same coupon reads +0.4927 % at n = 3, and the arc reads at most 1.946 %. The rule was applied as pre-registered, with no other number changed (D-22).
- **D-30 input.** D-30 was taken from the shakedown's `p0b.json` and is pending the 18b re-check.
- **D-45.** P0-A ran before the lumped-port fix. All 16 step models rebuild with unchanged hashes on the fixed code (section 2).
